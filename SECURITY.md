# Segurança

## Versões suportadas

A versão estável mais recente recebe correções de segurança.

## Relatar uma vulnerabilidade

Use **Security > Report a vulnerability** no GitHub, quando disponível. Não publique tokens, dados pessoais, links privados ou detalhes exploráveis em uma Issue pública.

Para problemas comuns de download que não envolvam segurança, abra uma Issue e informe apenas:

- versão do aplicativo;
- plataforma do link;
- mensagem de erro sem dados privados;
- passos mínimos para reproduzir.

Nunca envie cookies, senhas ou códigos de autenticação.
